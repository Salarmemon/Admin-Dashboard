# Admin Dashboard

A fully responsive and modern **Admin Dashboard** built as the final project for the Intermediate HTML and CSS course from [The Odin Project]
This project focuses on advanced layout techniques using **CSS Grid**, responsive design principles, and clean UI structuring while recreating a professional dashboard interface.

## Features

- Responsive dashboard layout
- Sidebar navigation
- Header with search functionality
- User profile section
- Project cards layout
- Announcements section
- Trending users section
- Modern UI design
- CSS Grid-based structure
- Hover effects and interactive styling

---

## Built With

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Google Fonts
- SVG Icons

## What I Learned

While building this project, I practiced and improved my understanding of:

- Advanced CSS Grid layouts
- Nested grids
- Responsive web design
- Structuring large layouts
- Positioning and alignment techniques
- Creating reusable UI sections
- Combining Grid and Flexbox effectively
- Building cleaner and more maintainable CSS
